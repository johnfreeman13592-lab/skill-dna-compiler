# Security policy

## Supported version

The latest public Beta release is the only supported version during the initial Beta period.

## Report a vulnerability privately

Do not open a public Issue for a security vulnerability. Use GitHub's private vulnerability
reporting feature on the public repository. Include the affected version, reproduction steps,
impact, and any suggested mitigation without including real API keys, private note contents,
credentials, or personal data.

If private vulnerability reporting is temporarily unavailable, open a public Issue containing
only a request for a private contact method. Do not include vulnerability details in that Issue.

## Sensitive information

Never submit any of the following in an Issue, Discussion, screenshot, log, or sample file:

- OpenAI API keys or other tokens
- Passwords or credential-store contents
- Private Obsidian notes or outbound payload JSON
- Local databases or database backups
- Personal names, addresses, internal URLs, or private filesystem paths

Replace sensitive values with clearly synthetic placeholders before sharing a reproduction.
