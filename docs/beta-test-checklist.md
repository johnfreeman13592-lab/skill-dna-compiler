# v0.1.0-beta.4 別Windows PC検証チェックリスト

既存Pythonは削除しません。テスト用コマンドプロンプトだけPATHを制限します。

## 準備

- [ ] ZIPと`.sha256`を同じフォルダへ置いた
- [ ] PowerShellの`Get-FileHash -Algorithm SHA256`結果が`.sha256`と一致した
- [ ] 「Windows セキュリティ」→「ウイルスと脅威の防止」が有効になっている
- [ ] 「ウイルスと脅威の防止の更新」でセキュリティ情報を更新した
- [ ] ZIPを右クリックし、「その他のオプションを確認」→「Microsoft Defenderでスキャンする」を実行した
- [ ] ZIP展開後の`Skill DNA Compiler`フォルダも同じ方法でスキャンした
- [ ] どちらも脅威が検出されなかった（検出された場合は許可や除外をせず、テストを止める）
- [ ] ZIPを日本語と空白を含むフォルダへ展開した

## Pythonへ依存しない起動

コマンドプロンプトを開き、次を実行します。この変更はそのウィンドウ内だけです。

```bat
set "PATH=C:\Windows\System32;C:\Windows"
where python
```

`情報: 指定されたパターンのファイルが見つかりませんでした。`と表示されることを確認します。
続けて、展開先に合わせた絶対パスでEXEを起動します。

```bat
"C:\テスト用フォルダ\Skill DNA Compiler\Skill DNA Compiler.exe"
```

- [ ] 外部Pythonなしでブラウザー画面が開いた
- [ ] 起動URLが`127.0.0.1`だった
- [ ] 2回目の起動が「既に起動しています」で停止した

## オフライン確認

- [ ] APIキーなしで起動できた
- [ ] `Sample Vault`を読み込めた
- [ ] モック抽出から候補レビュー、承認、Skill DNA化まで完了した
- [ ] 明示した出力先へ`SKILL.md`を出力できた
- [ ] 選択していないメモが送信JSONへ入っていなかった

## Credential Manager確認

- [ ] 架空のテスト文字列を保存でき、画面へ再表示されなかった
- [ ] 再起動後に「設定済み」と表示された
- [ ] 保存済みAPIキーを削除できた
- [ ] 実際のAPIキーを保存できた

## 少額の実API確認

- [ ] 個人情報や秘密を含まない架空メモ1件だけを選択した
- [ ] 送信JSONと料金上限を確認した
- [ ] 実API抽出を1回だけ実行し、出典付き候補を取得した
- [ ] APIキーやメモ本文がエラーログ、DB、生成Skillの不要箇所に残っていなかった
- [ ] テスト後に不要な資格情報とテストデータを削除した

実APIの実行前には、アプリに表示された最新の料金上限を記録してください。
