# Skill DNA Compiler Beta クイックスタート

## 最初の10分で試すこと

初回はAPIキーも実際のObsidianメモも必要ありません。次の無料・ローカルだけで完結する手順から始めて
ください。

```text
ZIPを展開する
  → EXEを起動する
  → 同梱Sample Vaultを選ぶ
  → モック抽出する（無料）
  → 元メモの根拠を確認する
  → 承認した候補をSKILL.mdへ出力する
```

モック抽出では外部APIを呼ばず、料金は発生しません。有料操作が可能になるのは、後から実メモを
選び、正確な送信JSONと料金上限を確認し、内容と料金の両方へ同意して、料金表示付きの実抽出
ボタンを押した場合だけです。

画面で迷った場合は、次の意味で読み替えてください。

- `Vault`：ObsidianのMarkdownメモが入ったフォルダー
- `候補`：選択したメモから見つかった、別の作業でも使えそうな指示やルール
- `根拠の確認`：候補が元メモに本当に書かれているか確かめる工程
- `Skill DNA`：承認した候補を版と根拠付きで保存したもの
- `SKILL.md`：Codexで利用する最終ファイル

## 1. 起動

1. ZIPを右クリックして**「すべて展開」**を選びます。
2. 展開した`Skill DNA Compiler`フォルダーを開きます。
3. `Skill DNA Compiler.exe`をダブルクリックします。
4. 黒い起動ウィンドウを閉じず、ブラウザーに表示された画面を使います。
5. 終了するときは黒い起動ウィンドウを閉じます。

Pythonのインストールは不要です。アプリ画面は外部ネットワークではなく、`127.0.0.1`だけで
動作します。

未署名Betaのため、Windows SmartScreenが警告する場合があります。公式Releaseページから取得した
ZIPであり、SHA-256が公開`.sha256`ファイルと一致する場合だけ続行してください。Betaを動かすために
セキュリティ製品を無効化したり、ウイルス対策の除外を追加したりしないでください。

## 2. 無料のSample Vault

1. **「同梱Sample Vaultを使う」**を押します。
2. **「Vaultを読み込む」**を押します。
3. サンプルメモを選び、**「送信内容を準備する」**を押します。
4. 伏字済みJSONを確認し、確認欄を選びます。
5. **「モック抽出を実行する」**を押します。実抽出ボタンは押しません。
6. 候補を開き、各指示が表示された根拠で支えられているか確認します。
7. 実際に確認した候補と各指示のDNA Traceだけを承認します。
8. 承認した候補をSkill DNAとして保存します。
9. 空のテスト用フォルダーを選び、全文プレビューを確認して`SKILL.md`を出力します。

モック抽出はOpenAI APIを呼ばないため料金はかかりません。初回は候補の文章を完璧に直すこと
より、根拠が各指示を支えているかの確認を優先してください。根拠が足りない場合は承認せず、
保留または却下できます。

## 3. 後で実抽出を行う場合のOpenAI APIキー（任意）

無料のSample Vault手順では、この節を飛ばしてください。

1. **「OpenAI APIキー設定」**を開きます。
2. APIキーをパスワード欄へ入力します。
3. **「Windows資格情報ストアへ保存」**を押します。

保存だけではAPI通信や料金は発生しません。配布版はWindows Credential Managerへ保存し、
Skill DNA CompilerのSQLite、ログ、生成Skillには保存しません。APIキーをメモ、Issue、チャット、
スクリーンショットへ貼り付けないでください。

削除するときは削除確認欄を選び、削除ボタンを押します。資格情報ストアが利用できない場合、
アプリは安全のため平文ファイルへ代替保存しません。

## 4. 実際のメモを使う場合（任意）

初回利用のSample Vault調査では、この節を使いません。

1. Obsidian Vaultのパスを入力し、読み込みます。
2. 外部AIへ送ってよいメモだけを明示選択します。
3. 伏字済み送信JSON、文字数、料金上限を確認します。
4. 2つの確認欄を選び、料金表示付きの実抽出ボタンを押します。
5. 出典と内容を人間が確認し、必要な候補だけを承認します。

選択していないメモは送信されません。機密情報の自動検出は保証ではないため、正確な送信JSONの
目視確認を省略しないでください。

## 5. データとアンインストール

- アプリ本体：ZIPを展開したフォルダー
- ローカルDB：`%LOCALAPPDATA%\SkillDNACompiler\SkillDNACompiler\skill-dna.db`
- DBバックアップ：DB隣の`skill-dna.db.backups`フォルダー
- 保存した場合のAPIキー：Windows Credential Manager

アプリ本体だけを消してもDBと保存済みAPIキーは残ります。完全に削除する場合は、最初にアプリ
画面からAPIキーを削除し、必要なバックアップを保管してから、アプリ本体と上記ユーザーデータフォルダーを
削除します。

## 6. 既知の制限

- Windows 10/11 x64限定
- コード署名とインストーラーは未提供
- 開発途中のBeta版。重要なデータは別にバックアップする
- ブラウザーのタブだけを閉じてもローカル処理は停止しない
- 自動テレメトリーとクラウド同期はない

## 7. 困ったとき

- ブラウザーが開かない：黒い起動ウィンドウを閉じず、表示された`127.0.0.1`のURLをブラウザーへ入力します。
- 2回目を起動できない：すでに開いている起動ウィンドウとブラウザー画面を使います。
- APIキーを持っていない：Sample Vaultとモック抽出はAPIキーなしで利用できます。
- 料金が心配：**「モック抽出を実行する」**だけを使い、実抽出ボタンは押しません。
- メモ選びに迷う：初回は同梱Sample Vaultだけを使います。
- SmartScreenやウイルス対策が止めた：急いで回避せず、公式の入手元とSHA-256を再確認し、
  不安が残る場合は中止します。
